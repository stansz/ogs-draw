# OGS Draw

A free, open-source collaborative whiteboard — customized for the [OGS Apps](https://ogsapps.cc) ecosystem.

**→ [draw.ogsapps.cc](https://draw.ogsapps.cc)**

---

## About

OGS Draw is based on [Excalidraw](https://github.com/excalidraw/excalidraw), an excellent open-source virtual whiteboard tool. We've customized it with:

- **OGS Apps branding** — navy blue theme, custom logo, welcome screen
- **Streamlined UI** — removed Excalidraw+ upsells, simplified menus and dialogs
- **Privacy-first** — no tracking, no ads, no data collection. Your data stays in your browser
- **Save to disk** — clean save/export workflow, no account required
